# .github

Repositorio de configuración de la cuenta. Los archivos de aquí se usan como
**valores por defecto en todos mis repositorios** que no tengan los suyos
propios.

| Archivo | Para qué sirve |
| :--- | :--- |
| `CONTRIBUTING.md` | Cómo colaborar: ramas, commits y pruebas |
| `SECURITY.md` | Cómo reportar una falla de seguridad |
| `CODE_OF_CONDUCT.md` | Reglas de convivencia |
| `.github/ISSUE_TEMPLATE/` | Formularios para reportar errores o pedir mejoras |
| `.github/pull_request_template.md` | Lista de verificación al abrir un Pull Request |

Más información: [documentación de GitHub sobre archivos de salud comunitaria](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
